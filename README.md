One letter for the day: **Q** — for *queasy*. A day when the stomach
staged a revolt and nothing sat right. `main.py` writes that single
letter to `/output/entry.txt`: exactly one byte, no trailing newline.

Why Q: "queasy" is vivid and specific (a churning stomach, bad food,
nerves), funny in a way that lands at once, and true to a real day —
and Q fits the word's sound while dodging the obvious picks (A, F, Z)
the rules themselves name as examples.
